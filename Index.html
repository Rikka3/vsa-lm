Chapter 01 · The problem

Every token leaves a brick behind

A transformer never forgets

For every token, every attention layer stores a key and a value vector. That pile is the KV cache, and it only ever grows. Scroll to feed it tokens.

Memory grows linearly

For Llama-3.2-1B the cache is 16 MB at 512 tokens and 2,048 MB at 65,536. Long chats, long documents and long reasoning traces all pay that rent.

…and decoding slows down

Each new token has to attend over the whole pile. Measured decode speed drops from 148 tok/s to 51 tok/s at 64k context.

Chapter 02 · How VSA works

Fold the past into one fixed block

1 · Project

Each incoming token is projected into a key k and a value v. VSA-LM uses positive, sharpened features plus an 8-tap causal local convolution.

2 · Bind with an outer product

k ⊗ v turns two vectors into a D×D imprint of the token. Every cell is k[i]·v[j].

3 · Decay and add

M_t = γ·M_(t−1) + k_t ⊗ v_t
Old imprints fade by γ while new ones are stacked on top. Learned multi-scale decay (γ ∈ [0.50, 0.992]) gives both short- and long-memory heads. The matrix never gets bigger.

4 · Read with the query

y_t = (1−γ)/√D · M_t q_t
One matrix–vector product per token, however long the context is. That is O(1) decode, done in a fused Triton kernel.

Chapter 03 · Head to head

Same model family. Longer and longer context.

Short context: a tie

From 512 to 8k tokens both models decode at about 149 tok/s, but VSA already carries a far smaller cache (67 MB vs 256 MB at 8k).

32k: pulling away

The transformer slows to 85.5 tok/s. VSA-Llama holds 149.7 tok/s, which is 1.75× faster.

64k: 2.43× faster, 4× smaller

124.7 vs 51.4 tok/s and 515 MB vs 2,048 MB of cache (−74.9%). These are measured numbers for VSA-Llama-3.2-1B vs unquantized Llama-3.2-1B.

Chapter 04 · The hybrid stack

Three VSA layers for every softmax layer

75% VSA · 25% softmax

Every 4th layer keeps exact softmax attention as an anchor for precise recall. The other three of every four layers compress context into a fixed state, so only the teal layers' caches keep growing.

Convert any donor model

A Hugging Face model is surgically converted in about 20–30 seconds, then healed with VSA-FastDistill from the donor. Supported donors: Llama, Qwen, DeepSeek-Distill, Mistral and SmolLM.

Chapter 05 · Exact unlearning

Memorize. Then subtract it back out.

memorize(doc)

A document is streamed into the live state. Each token adds its decayed k⊗v imprint into the same fixed matrix, with no new rows and no new cache.

The state is linear

M is a plain sum of outer products, so the model knows exactly how much each document contributed.

forget(doc)

M ← M − Σ γ^Δt · k_t ⊗ v_t
The document is removed surgically in under 1 ms, with residual error below 1e-5.

Chapter 06 · VSAMemoryBank

Context as cartridges on disk

Encode to .vsa cartridges

Documents or past chats are encoded into compact .vsa state files on your SSD. They take 0.00 MB of idle GPU/CPU RAM.

Route the query

A question comes in, and the bank picks the right cartridge in under 20 ms.

Mount, answer, unmount

The state is mounted, the model answers, and the state is then algebraically erased: 4/4 exact secret retrieval with a 0.0 erase residual.

Chapter 07 · OpenMythos latent thinking

Think inside the block, not on the cache

K recurrent passes

Instead of writing out more chain-of-thought tokens, the model runs K latent passes entirely inside the fixed VSA state matrices. The softmax KV caches stay frozen.

K = 0 → K = 4

On VSA-DeepSeek-R1-Qwen-1.5B, answer CE loss falls from 1.218 to 0.274 and true-token confidence rises from 52.95% to 81.65%. Memory growth during thinking is 0 bytes.

Crafting table

Quickstart

git clone https://github.com/Rikka3/vsa-lm.git
cd vsa-lm
pip install -r requirements.txt

# Train a 6-VSA + 2-Softmax hybrid from scratch
python -m vsa_lm train --run vsa --max-len 512
# Convert a donor model, then heal it
python -m vsa_lm convert --donor deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B \
    --out deepseek_vsa_init.pth --hybrid-every 4
python -m vsa_lm heal --ckpt deepseek_vsa_init.pth \
    --donor deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B \
    --out-prefix deepseek_vsa --tokens 60000000 --lr 1.5e-4 --kd 1.0
